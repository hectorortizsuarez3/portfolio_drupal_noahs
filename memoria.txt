Objetivo actual

Desinstalar Layout Builder y Layout Discovery en el proyecto clonado.

Problema actual

Drupal no permite desinstalar Layout Builder desde Extend → Uninstall.

Aunque:

Ningún content type (Basic page, Article, Proyecto) tiene Layout Builder activado.

Ningún block type lo usa.

No existen tablas layout_builder en la base de datos.

Drupal sigue detectando una dependencia residual del campo técnico:

node.layout_builder__layout

Layout Builder no se podía desinstalar inicialmente aunque no estuviera activo en ningún content type.
El bloqueo venía de configuración residual interna (entity_view_display + validadores de campos) y de cachés de Drupal, no de uso real.
Fue necesario:

limpiar dependencias de core.entity_view_display.node.page.default

reconstruir cachés (drush cr)

y forzar a Drupal a recalcular los validadores
hasta que la UI permitió la desinstalación.
Una vez hecho esto al final la interfaz permitió desinstalar layout builder y layout Discovery, con drupal estable (frontend y admin ok, sin warnings).
